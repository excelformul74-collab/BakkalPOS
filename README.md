# BakkalPOS — Barkodlu Satış ve Market Yönetimi

Bakkal, büfe, tekel ve mahalle marketleri için barkodlu satış programı.
Satış, stok, kasa, veresiye, tedarikçi, gider ve raporlar tek programda.

## ⬇️ İndir

**[BakkalPOS kurulum dosyasını indir](https://github.com/excelformul74-collab/BakkalPOS/releases/latest/download/BakkalPOS_Kurulum.exe)**

1. Yukarıdaki bağlantıya tıklayın, `BakkalPOS_Kurulum.exe` iner.
2. İnen dosyaya çift tıklayın. Windows "Bilgisayarınız korundu" derse **Ek bilgi → Yine de çalıştır** deyin.
3. Kurulum bitince masaüstündeki **BakkalPOS** simgesiyle programı açın.
4. Bilgilerinizi girip **DENEMEYİ BAŞLAT** deyin — ücretsiz deneme hemen başlar, lisans kodu gerekmez.

Gereksinim: Windows 10 / 11 (64 bit). İlk açılışta internet bağlantısı gerekir.
